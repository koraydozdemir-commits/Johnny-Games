# Spore Origins — browser edition

This entry is a browser-based recreation for Johnny Games, built with Canvas and keyboard/touch controls. It uses selected visual assets recovered from the user-provided Spore Origins APK (logo, underwater environment, nutrient orb, and organism sprites). It is not the original Android engine or a byte-for-byte port.

Controls: WASD / arrow keys to swim; Space or Shift to burst; drag on touch screens to steer. Collect nutrients to gain mass and evolve; avoid hunters or burst through them.

Assets are stored in `games/spore-assets/`.
